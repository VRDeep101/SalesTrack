# TradeGrid

A local-first trading finance dashboard built with vanilla HTML, CSS and JavaScript.

## Run
Open `index.html` in a modern browser. No backend or build step is required.

## Included
- Dark/light theme
- USD/INR conversion with configurable exchange rate in `localStorage`
- Balance management
- Daily income/expense/profit calculations
- Sales tracker
- Interactive 7-day line/bar/donut charts
- Daily checklist
- Recurring task scheduler
- Transaction ledger
- CSV export
- Print/save-as-PDF daily report
- Local persistence
- Responsive layout

## Data
All data is stored under `localStorage["tradegrid-v1"]`.
